# Artifact Manifest

This folder contains the polished deliverables for the NYC Taxi LLM-driven data-science assignment.

- `README.md` — full end-to-end project documentation for GitHub.
- `MEDIUM_ARTICLE.md` — long-form Medium-style article ready to adapt/publish.
- `PRESENTATION_NARRATIVE.md` — 12-slide speaking narrative for an 8–10 minute presentation.
- `assets/` — seven strongest visualizations from the experiment.
- `results/` — verified model-comparison and model-interpretation CSV outputs.

The large raw NYC dataset is intentionally not duplicated into this package.
