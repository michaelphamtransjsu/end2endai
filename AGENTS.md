# Repository collaboration rules

- Each project agent owns exactly one numbered project directory.
- An agent must not modify another numbered directory.
- All projects must run locally without paid services.
- Never commit secrets, credentials, `node_modules`, virtual environments,
  large datasets, caches, or generated build directories.
- Never fabricate metrics, screenshots, experiments, or test results.
- Prefer a small verified vertical slice over unfinished features.
- Every project requires a README with exact installation, test, training,
  and startup commands.
- Data-science projects require a CRISP-DM report.
- Every project requires automated smoke tests.
- Agents may create commits and a pull request.
- Agents must not merge, deploy, force-push, or change repository settings.
